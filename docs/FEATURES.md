# Features

Baseline inventory of what `eco-mods-public` currently ships. Use this as a fixed reference point when evaluating scope changes (additions, removals, or feature drift) over time.

Scope: nine mods under `Mods/UserCode/`, plus the code-generation and packaging tooling at the repo root. Targets `Eco.ReferenceAssemblies` v0.13.0-beta (Cycle 13).

## Mod clusters

### BunWulf family

A loose suite of mods sharing the BunWulf branding. Adds professions, crops, and recipes that broaden the farming and chemistry side of the tech tree.

#### BunWulfAgricultural

Extended farming content. Adds crop and plant species plus a set of recipes that give Farming new economic outlets.

- **Plants** - 29 plant species files (Agave, Beans, Beets, Bolete/Amanita/Cookeina/Crimini mushrooms, Camas, Clam, Corn, Cotton, Creosote Bush, Fern, Fireweed, Flax, Huckleberry, Kelp, Orchid, Papaya, Pineapple, Prickly Pear, Pumpkin, Rice, Sunflower, Taro, Tomatoes, Trillium, Urchin, Wheat). Generated from `templates/plant.template`.
- **Recipes** - Biochar charcoal burning (charcoal + vegetables to charcoal + oil byproduct), compost decomposition, compost mixing, fabric paper, flax processing, lubricants, oil, rice paper, shredded crops.

#### BunWulfBiochemical

Adds a **Biochemist** profession positioned as a sustainable, plant-based alternative to Oil Drilling. Intentionally slower than oil, not a strict replacement.

- **Profession / skill** - Biochemist tech tree.
- **Workstation** - Chemical Laboratory world object.
- **Recipes** - Biofuel from plastic + ethanol, plant-based bioplastic (vegetables + fat), tree rubber (Ceiba log + fat), coal-fat epoxy, coal-based nylon, ethanol from any vegetable, HyperPhyto.

#### BunWulfEducational

Adds a **Librarian** profession that can craft every skill book and every research paper at basic proficiency, plus the ink and paper supporting them.

- **Profession / skill** - Librarian tech tree (`Tech/Librarian.cs`).
- **Upgrades** - Basic, Advanced, Modern librarian upgrades.
- **Recipes** - 100+ files under `Recipes/Tech/` and `Recipes/Item/`, generated by `main.cs` from Eco core game files. Stays in sync with vanilla skill books across game updates.

#### BunWulfHardwareCo

Two specialty hardware items.

- **Sledgehammer** - Tier-2 iron building tool dedicated to deconstruction. Repairs through Blacksmith.
- **Low Tech Streetlamp** - Mechanics-gated lighting recipe (iron bars + glass).

### Standalone mods

#### DirectCarbonCapture

Late-game atmospheric CO2 mitigation via a Direct Air Capture Fan world object. Power-hungry, consumes carbon filters, scales with the world's pollution multiplier (less effective when pollution is high). Pollution clear radius around the fan.

Status note: source files are currently fully commented out. Treat as dormant or pending revival rather than active gameplay content.

#### EcoNil

Weather and moisture control. Two world objects that read and adjust the soil-moisture and rainfall world layers within a radius.

- **Cloud Seeder** - Increases rainfall and soil moisture. Optimal placement 50 blocks apart, stacking placements amplifies effect.
- **Dehydrator** - Decreases rainfall and soil moisture, same placement guidance.
- **Underlying mechanics** - Hourly tick that compares local averages against an adjustment target and writes back to `LayerNames.SoilMoisture` and `LayerNames.Rainfall`.

#### MinesQuarries

Infinite-but-expensive extraction. Designed around vertical integration. Profit-negative for many configurations unless the player processes downstream.

- **Mines** - 5 ore types (iron, copper, gold, coal, sulfur). Placed on top of an ore deposit, run until that deposit is exhausted. Three recipe tiers per mine (mooring rope, dynamite, mining charge), progressively more efficient and more expensive. Most produce waste rock. Mechanics-gated (requires wooden elevator).
- **Quarries** - 4 stone types (sandstone, limestone, granite, shale). Must be placed against a primarily-matching cliff face, no waste byproduct. Available early (mortared stone unlock).
- **Pits** - 3 types (sand, dirt, clay). Documented but spec is TODO.
- **Custom components** - Status components per object type, inventory restrictions, search/discovery helper.

#### ShopBoat

Mobile shop world object. Combines a boat with a store, public storage, and a movable property link, so a shop can be parked or sailed.

- **Components** - Boat + vehicle + ladder + store + public storage + fuel supply + tailings report + movable link + standalone auth.
- **Skill gating** - Repair via Shipwright + Self Improvement.

#### WorldCounter

World statistics tracking via a **Bookkeeping Desk** world object. Walks blocks within a radius around the desk and counts each block type, exposed through a status component and tooltip surface.

## Tooling and code generation

Not gameplay features, but part of what the repo ships and worth tracking when evaluating scope.

- **`main.cs`** - CLI tool. Reads Eco core game files and generates the BunWulfEducational Librarian recipes via regex transformation.
- **`tasks.py` + `util.py` + `recipes.yml` + `templates/`** - Python `invoke` pipeline for asset packaging, agricultural mod generation, and deployment to local Steam install paths (Windows and Linux).
- **Deployment commands** - `invoke copy-assets`, `invoke zip-assets --mod=<Name>`, `invoke push-asset --mod=<Name>`.
- **Distribution format** - Per-mod `.zip` at the repo root, extracted by users into the Eco server root.

## Cross-cutting design intent

- **Sustainability framing** - Biochemist, MinesQuarries, EcoNil, and DirectCarbonCapture all sit on a "renewable but expensive" axis rather than "free upgrade".
- **Vertical integration as a balance lever** - MinesQuarries explicitly relies on it. Biochemist's pricing is tuned against Oil Drilling's full chain.
- **Vanilla parity by generation** - BunWulfEducational regenerates from Eco core, so it tracks vanilla skill books across patches without hand maintenance.
