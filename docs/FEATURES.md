# Features

Baseline of `eco-mods-public`. Track scope drift over time. Nine mods under `Mods/UserCode/` plus codegen and packaging tooling. Targets `Eco.ReferenceAssemblies` v0.13.0-beta (Cycle 13).

## BunWulf family

A loose suite of professions, crops, and recipes broadening the farming and chemistry side of the tech tree.

### BunWulfAgricultural

Extended farming. 29 plant species (Agave, Beans, Camas, Cotton, Corn, Flax, Kelp, Pumpkin, Rice, Tomatoes, and more), generated from `templates/plant.template`. Recipes: biochar burning, compost decomposition + mixing, fabric paper, flax processing, lubricants, oil, rice paper, shredded crops.

### BunWulfBiochemical

A **Biochemist** profession, sustainable plant-based alternative to Oil Drilling. Intentionally slower. Chemical Laboratory workstation. Recipes: biofuel from plastic + ethanol, bioplastic, tree rubber, coal-fat epoxy, coal-based nylon, ethanol from any vegetable, HyperPhyto.

### BunWulfEducational

A **Librarian** profession that crafts every skill book + research paper at basic proficiency, plus ink and paper. 100+ recipe files under `Recipes/{Tech,Item}/`, generated by `main.cs` from Eco core so it tracks vanilla across patches. Basic / Advanced / Modern librarian upgrades.

### BunWulfHardwareCo

Two specialty hardware items: **Sledgehammer** (tier-2 iron deconstruction tool, Blacksmith repair), **Low Tech Streetlamp** (Mechanics-gated lighting).

## Standalone mods

### DirectCarbonCapture

Late-game atmospheric CO2 mitigation via a Direct Air Capture Fan. Power-hungry, consumes carbon filters, scales against world pollution. Source currently fully commented out; treat as dormant.

### EcoNil

Weather + moisture control via two world objects reading/adjusting `LayerNames.SoilMoisture` and `LayerNames.Rainfall` within a radius. **Cloud Seeder** raises; **Dehydrator** lowers. Optimal 50-block spacing; stacks amplify. Hourly tick compares local averages to target.

### MinesQuarries

Infinite-but-expensive extraction designed around vertical integration; profit-negative for many configs unless processed downstream.

- **Mines** - 5 ore types (iron, copper, gold, coal, sulfur). Placed on a deposit; runs to exhaustion. Three recipe tiers per mine (rope, dynamite, mining charge). Most produce waste rock. Mechanics-gated.
- **Quarries** - 4 stone types (sandstone, limestone, granite, shale). Must be placed against a primarily-matching cliff face, no waste. Available early.
- **Pits** - 3 types (sand, dirt, clay). Spec TODO.

### ShopBoat

Mobile shop world object combining boat + store + public storage + movable property link + fuel supply + tailings + auth. Shipwright + Self Improvement to repair.

### WorldCounter

World statistics via a **Bookkeeping Desk**. Walks blocks within a radius, counts block types, exposes via status component + tooltip.

## Tooling and codegen

- `main.cs` reads Eco core files, generates BunWulfEducational Librarian recipes via regex transformation.
- `scripts/mods.py` + `util.py` + `recipes.yml` + `templates/` - Python pipeline for asset packaging, agricultural codegen, deployment. Wrapped by `coily` verbs.
- Deploy: `coily copy-assets`, `coily zip-assets mod=<Name>`, `coily push-asset mod=<Name>`. Upload step lives in `coily gaming eco mod push`.
- Distribution: per-mod `.zip` at repo root.

## Cross-cutting design

- Sustainability framing on a "renewable but expensive" axis (Biochemist, MinesQuarries, EcoNil, DirectCarbonCapture).
- Vertical integration as a balance lever (MinesQuarries, Biochemist).
- Vanilla parity by generation (BunWulfEducational regenerates from Eco core).
